# Institution logos

These PNGs are web renditions of the institution logo assets used in the survey manuscript. Original artwork, colors, and aspect ratios are preserved. They are rendered at four times their README display dimensions, on white backgrounds for legibility in light and dark themes.

Independent Researcher (affiliation 15) has no logo. Numbering and institution labels are maintained in the root README. The source provenance below is carried over from the manuscript's logo documentation (September 29, 2026).

Peer AI is confirmed as getpeer.ai; UCSD is retained unchanged by author request. JHU retains the visually checked academic-project source because the official download was inaccessible. Humani Labs uses the author-provided company LinkedIn profile. NUS is a component of an official Computing header. These source distinctions and small-display limitations are recorded in the audit.
